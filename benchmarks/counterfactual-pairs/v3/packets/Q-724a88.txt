The address backfill will geocode 3.2 million rows through the vendor geocoding API using a single API key.
The key's contract allows at most 50 requests per second in total, and exceeding it in any one-second window suspends the key for 24 hours.
The job runs 12 worker processes in parallel with no shared coordination between them, and the count stays fixed for the whole run.
Each worker is held by a client-side limiter to at most 5 requests in any one-second window.
Retries after an HTTP 500 draw from the same limiter as first attempts, so they never add traffic on top of the worker's rate.
No other service or job uses this API key while the backfill is running.
Requirement: the backfill must stay within the contracted rate, because a suspension would also stop live checkout address lookups for a full day.
