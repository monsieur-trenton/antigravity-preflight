The orders PostgreSQL database must be restorable to any point in time from 14 days ago up to 5 minutes ago.
A full base backup runs every Sunday at 02:00 UTC, and WAL segments are archived continuously, each one within 60 seconds of being written.
A restore to a chosen time starts from the latest base backup taken before that time and replays archived WAL forward from it.
Since base backups are weekly, reaching a point 14 days back can require a base backup up to 21 days old together with all WAL written after it.
Base backups and archived WAL are both retained for 7 days, and a nightly lifecycle job deletes anything older.
The lifecycle job holds delete permission on the backup bucket, but its rule matches only objects older than the retention limit.
The backup bucket lives in a separate account where the database hosts can write new objects but cannot overwrite or delete existing ones.
Each month a restore to a randomly chosen point between 13 and 14 days back is rehearsed on a scratch instance.
