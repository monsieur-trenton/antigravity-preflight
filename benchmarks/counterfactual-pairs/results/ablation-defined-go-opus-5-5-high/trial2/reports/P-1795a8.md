# Review: `orders.shipped_at` Migration

The plan works as written. Each step's precondition is met by the step before it.

**Step 1: add nullable `shipped_at`.** Adding a nullable column with no default is a cheap metadata change on most engines, even at about 2M rows. Making it nullable is correct, because existing rows have no value yet.

**Step 2: backfill from `shipments`.** The plan says `shipments` holds a non-null `shipped_at` for every order. So every existing row gets a non-null value. The maintenance window means no new orders arrive during the migration, so no rows are left NULL.

**Step 3: add NOT NULL.** After Step 2 no NULLs remain, so the constraint validates. The steps run strictly in order, so the constraint never runs before the backfill.

**Rollback: drop the column.** This fully reverses Steps 1–3 from any failure point:
- If Step 1 fails, there is nothing to drop. The script should use `DROP COLUMN IF EXISTS` or check first.
- If Step 2 or 3 fails, dropping the column removes the partial data and any constraint along with it.

Nothing in the plan will fail or break a rule it states.

## Optional robustness suggestions (not required)

1. **Multiple shipments per order.** If an order can have more than one `shipments` row, a plain `UPDATE … FROM` join picks a value unpredictably. Choosing one on purpose would make the result deterministic, for example `MIN(shipped_at)` or the latest shipment.
2. **Verify before Step 3.** Run `SELECT COUNT(*) FROM orders WHERE shipped_at IS NULL` and stop if it isn't 0. You'd get a clear failure message instead of a constraint error.
3. **Batch the backfill.** Updating 2M rows in one statement creates a large transaction and lots of WAL/undo. Batching, for example by primary-key ranges, reduces lock time and makes progress visible.
4. **Make rollback idempotent.** Use `DROP COLUMN IF EXISTS` so the script is safe whichever step failed.
5. **Constraint validation cost.** On engines like PostgreSQL, `SET NOT NULL` scans the whole table. That's fine in a maintenance window at this size, but include it in your timing estimate.
