Please review this plan.

The reporting API will cache rendered dashboard responses in a single Redis cluster that is shared by every customer tenant.
The gateway authenticates each request and attaches the caller's tenant_id before the request reaches the dashboard handler.
Dashboard IDs are assigned per tenant starting from 1, so the same dashboard ID, such as 42, exists in many tenants with different data behind it.
The cache key is "dash:{dashboard_id}:{range}", and the handler only ever reads or writes the key built from the current request.
Every dashboard is visible to all users inside its tenant, so the key deliberately leaves out the user ID.
Entries expire after 300 seconds, and any edit to a dashboard deletes its cached entries at once.
Isolation rule: a response cached for one tenant must never be returned to a caller belonging to a different tenant.
