For orders-api, both the TLS server certificate and its issuing CA are being replaced, moving from 'Internal Root 2023' to 'Internal Root 2026' with every existing client left running, and connectivity must never drop for any client.
A client trusts the server certificate only when it chains up to a root found in the client's local trust bundle, which is re-read in place every 15 minutes without closing open connections.
Up to the switch on day 7, the server continues to serve its current 'Internal Root 2023' certificate, which remains good until day 60.
Every client is sent a replacement trust bundle on day 1 that holds 'Internal Root 2023' and 'Internal Root 2026' together.
The switch gets a date only after the fleet inventory on day 3 lists every client with a bundle hash covering both roots.
Starting on day 7, the server presents a fresh certificate signed by 'Internal Root 2026' and includes the full chain with it.
Both roots share one subject name and are told apart solely by key identifier, and in staging, clients holding a bundle with the pair accepted certificates from each root.
'Internal Root 2023' is dropped from the trust bundle on day 5, at which point its private key, held offline from day 1 onward, is destroyed.
