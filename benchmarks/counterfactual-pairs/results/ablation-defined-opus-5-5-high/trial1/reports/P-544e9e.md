# Review: `load_config` raises `ConfigError` instead of returning `None`

The plan looks sound. Each listed caller gets a matching handler, and `main()` keeps its existing behaviour: it prints "no config" and exits with status 2. Nothing in the plan will fail as written. There are some gaps worth closing.

## Issues and suggested changes

1. **`main()` has no test coverage.** It is the only caller whose observable behaviour, the message and the exit status 2, must stay the same. It is also the one caller left out of the tests. Add a test that runs `main()` with a missing config path and checks that it prints "no config" and exits with status 2 (for example, with `pytest.raises(SystemExit)` and captured stdout or stderr).

2. **`load_config` itself needs a test.** Add a direct test that a missing file raises `ConfigError`. Any existing test that checks for a `None` return will now fail, and the plan doesn't mention updating it.

3. **Make sure no other code relies on the `None` return.** The plan names three callers. Search the codebase for every call to `load_config`, including scripts, helper functions and tests, plus any `if cfg is None` checks further along. Any caller that is missed will now crash with an unhandled exception instead of handling `None`.

4. **Keep `ConfigError` narrow, or catch it narrowly.** The plan says `ConfigError` is raised "for a missing file". If `ConfigError` is also raised, now or later, for parse or permission errors, `schedule()` and `report()` will quietly use the defaults when a config is malformed. That would hide real problems. Either use a specific subclass such as `ConfigNotFoundError` for this case, or state in a docstring and a test that only a missing file triggers the fallback.

5. **Check that the fallback in `schedule()` and `report()` is intended.** The plan doesn't say what these functions did before when they received `None`. If they already used the defaults, this is just a refactor. If they did something else, such as raising or skipping, then this is a behaviour change and should be called out.

6. **Minor:** The note that config files are plain text and under 10 KB doesn't affect this change. It can be dropped, or it should say why it matters.
