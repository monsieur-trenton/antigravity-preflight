# Historical evidence

These files preserve the initial experiment's prompts/cases, responses, heuristic scores and relevant source. They are historical evidence, not the current evaluator or supported native route. The original scorecard's PASS labels are retained unchanged; the parent case study explains their limits.

The original response file has one host-local citation URL redacted. Corpus origin labels and the direct runner's host executable path are also redacted. `../provenance.json` records original/public hashes and every transformation. The runner and original scorer are inert `.txt` files. The historical runner bypassed the qualified launcher and used `--dangerously-skip-permissions`; do not use it to repeat the experiment. Use separately authorized, applicable qualified routes for future model runs.

The prompt builder supplied only each candidate_plan, not its separate ground_truth oracle. The original labels and keyword list remain available for retrospective inspection; a future blind test must keep its oracles outside the reviewer packet. These cases are reconstructions, not a replay of the original project failures.
