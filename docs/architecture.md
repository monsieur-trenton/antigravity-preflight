# Architecture

The portable skill defines a review process. The native runtime implements a separately qualified transport. Project policy belongs to the reviewed project.

| Layer | Responsibility | Does not establish |
| --- | --- | --- |
| Packet | Scope, authority, snapshots, hashes, contracts and questions | That omitted context was inspected |
| Reviewer | Advisory findings with coverage and exact quotations | Permission to change or release code |
| Citation utility | Verify supplied quotes at snapshot-local lines | Complete extraction, reading or factual support |
| Codex adjudication | Check every premise and preserve dispositions | The independent review required by project policy |
| Native launcher | Bound inputs, transport, model configuration and cleanup | Universal containment, backend request counts or semantic acceptance |

Completeness (COMPLETE/INCOMPLETE), findings assessment (BLOCKERS_FOUND/CHANGES_RECOMMENDED/NO_BLOCKERS_FOUND), and readiness are separate decisions. Missing required evidence withholds readiness without inventing a code defect. Candidate changes invalidate affected evidence.

The skill's scripts support local citation preparation/checking. The native runtimes are separate sibling packages: `runtime/flash-high` preserves its original six files, while `runtime/argon-high` publishes the seven owner-activated r15 files including the registry. Both support PLAN and DIFF packets. Installation of the manual skill does not install or activate the native route. Native use requires a retained repository checkout and the runtime runbook.

For Argon r15, preparation deterministically assembles the request and declared source bytes into the review prompt, preserving the original request separately. The schema-v2 plan binds the exact workspace inventory, source/request parity, selected profile and assembled prompt. Before launch and at closing, the runner checks inventory, full POSIX modes, symlinks, special bits and prompt parity. Receipts add sanitized init-catalogue evidence, registered PID/PGID observations and bounded settlement results. These observations do not establish provider consumption, exact tool-set equality, arbitrary descendant containment or process identity across PID reuse.

Argon r15 assembles the request and declared source bytes deterministically. Its schema-v2 plan binds workspace inventory, full POSIX modes, source/request parity and profile. Before launch and at closing, the runner checks that inventory and assembled prompt. Receipts add sanitized init-catalogue telemetry and bounded registered-child/group observations with wall and host-monotonic timestamps. These do not establish exact enabled tools, process identity across reuse, arbitrary descendant containment or provider consumption.
