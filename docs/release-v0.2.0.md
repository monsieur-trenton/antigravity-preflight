# Antigravity Preflight 0.2.0

Adds explicitly selected Gemini 4 Argon / High (`gemini-4-argon-high`, effort `high`, `useG1Credits=true`) for commissioned native CLI reviews. Manual Flash remains the default and the original Flash runtime is unchanged.

The seven accepted Argon runtime files are published byte-for-byte, with registry and provenance pins, sanitized source-host qualification/activation records, a portable offline harness, and installation guidance. Native binaries, credentials and private qualification packets are excluded.

Publication validation runs two fresh 618-case Argon normal/profile suites and 40 saved-envelope controls, alongside the existing Flash, citation and benchmark checks. No live models are called. The 1,714-case historical source-host envelope includes private denial drivers and is not the portable suite's count.

Source-host activation does not transfer to another machine. Qualification remains finite and acceptance retains independence, containment and verification risks. See [Argon use and limitations](argon-high.md) and [review reconciliation](reviews/2026-10-17-reconciliation.md). Runtime hardening remains separate work requiring affected requalification.
